# Icon assets

These are the **brand / social icons** shipped with the design system as inline SVG. They follow `currentColor` so they take the surrounding text color (usually `--color-text-muted`).

| File              | Use                                  |
| :---------------- | :----------------------------------- |
| `github.svg`      | GitHub footer link                   |
| `linkedin.svg`    | LinkedIn footer link                 |
| `twitter.svg`     | X / Twitter footer link              |
| `rss.svg`         | RSS feed link                        |
| `wordpress.svg`   | WordPress.org footer link            |

For **UI affordance icons** (copy, chevron, search, sun/moon, etc.) the UI kit pulls from [Lucide](https://lucide.dev) at 20px / 24px, 1.5px stroke. Lucide is a substitution flagged in the README — swap it out if Ivan prefers Phosphor or Heroicons.
