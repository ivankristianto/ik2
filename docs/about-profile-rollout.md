# Roll out the About profile

The About template reads the existing page’s `post_content`. The theme release updates the `ik2/about-page` pattern and adds its styles. The stored About blocks need a separate update. The stylesheet still supports the previous blocks during the interval between those two steps.

1. Build the theme assets and preview the `ik2/about-page` pattern in a disposable WordPress install. With the IK2 theme active and only the About page present, run the [page regeneration script](../wp-content/themes/ik2/bin/regen-page-content.php) using `wp eval-file`. It expands the child patterns and strips their pattern-instance locks. Export the resulting markup with `wp post get <about-id> --field=post_content`.
2. Before publishing the content update, back up the live About page’s raw content and check for edits made since the design review. Fold any edits worth keeping into the reviewed replacement markup. The detailed employment and community history is on the [resume](https://www.ivankristianto.com/resume/). The new About copy retains the 2019 WordCamp US volunteer entry.
3. After the theme release is live, update only `content` on the existing [About page](https://www.ivankristianto.com/about/) using the WordPress Pages REST endpoint. Resolve its ID from the `about` slug and use the existing authenticated content workflow. Keep the page ID, slug, title, template and SEO metadata. The broad regeneration script is for local fixtures.
4. Read back the page and check for the `Ivan Kristianto` heading, the Articles and Projects links, and the Resume and Contact section. Check the published page at phone and desktop widths. If necessary, restore the backed-up About content through the same endpoint. The legacy styles support the restored blocks.
